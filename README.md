## ✨ Features

- **Dynamic 3D Geometry**: Switch seamlessly between Torus Knot, Icosahedron, Quantum Sphere, and Cyber Cube.
- **Particle Galaxy & Nebula**: 12,500+ real-time GPU particle starfield with depth simulation and inertia tracking.
- **Interactive Orbit Controls**: Drag to rotate, scroll to zoom, and touch-gestures enabled for mobile devices.
- **Cyberpunk Glassmorphic HUD**: Floating UI with real-time FPS counter, rotation speed regulator, and multi-color theme selector.
- **Wireframe & Shading Modes**: Live toggle between physical metalness/clearcoat materials and cybernetic wireframes.
- **Zero-Config Deployment**: Optimized build pipeline ready for 1-click deployment on Vercel or Netlify.

## 🚀 Quick Start (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```

## 🌐 Deploy Live to Vercel / Netlify

### Option A: Deploy with Vercel (Recommended)
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **"Add New..."** -> **"Project"**.
3. Import the `levelx3D` repository (`nikhilmali007/levelx3D`).
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**. Your site will be live instantly with a free `*.vercel.app` domain and automatic HTTPS!

### Option B: Deploy with Netlify
1. Go to [netlify.com](https://netlify.com) and link your GitHub.
2. Select `levelx3D`.
3. Set build command to `npm run build` and publish directory to `dist`.
4. Click **Deploy Site**.
